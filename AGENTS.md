# Repository instructions

## Keep both READMEs synchronized

- `README.md` is the English GitHub landing page. `README.zh-CN.md` is its Chinese counterpart.
- Whenever either README is updated, update both files in the same change. When a code change affects documented behavior, setup, commands, configuration, deployment, or project status, reflect it in both READMEs.
- Keep their substantive information aligned: features, limitations, prerequisites, commands, environment variables, verification results, deployment status, and documentation links. Wording may differ naturally between languages.
- Retain the language links: English README links to `README.zh-CN.md`; Chinese README links to `README.md`.
- Before finishing a README change, read both versions and check their links and commands. Do not update only one version or use stale translations.
- Keep credentials and actual business records out of both READMEs. Distinguish tested behavior from work that still needs verification.
