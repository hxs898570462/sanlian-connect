## 反馈删除与智能打分增量验收（2026-11-07）

- 新增删除能力：`DELETE /api/feedbacks/:id` 与 `DELETE /api/suggestions/:id`，仅提交本人可删除自己的反馈/建议；已被门店回复的条目不可删除（防止覆盖服务记录）。「读者一隅」反馈与建议合并列表中，未回复条目显示「删除」按钮，点击后需确认，删除成功即时刷新列表并更新统计。
- 新增打分引擎 `server/feedback-scoring.js`（Node 与浏览器可复用）：沿用《作业/softr复现/keyword_rules.csv》51 条基准权重并扩展阅读活动场景三组词条（阅读活动与内容、服务与体验建议、无意义与噪声）。总分 = 命中词条权重累加（问题词加分、表扬词减分）+ 星级补偿（活动反馈 1 星 +12、2 星 +6）；提交时落库 `score`、`score_level`、`score_hits`。安全与合规词条命中即硬升级为高优先级；管理端排序与筛选时另按当前时间计算 SLA 等待加成（待处理超 24 小时 +4、超 48 小时 +8）。
- 升级迁移 v3：`feedbacks` 与 `suggestions` 增加打分三列，存量数据在启动时按同一引擎回填；回填与迁移在建议锁内的事务中执行，重复启动不重复执行。
- 管理后台：反馈/建议列表默认按优先级总分降序（同分按时间倒序），每条展示优先级徽章（高/中/低）与命中词条标签，新增「仅看高优先级」筛选；汇总卡增加「高优先级」计数（待处理/处理中且总分 ≥60 或被安全词条硬升级）。用户示例实测：「消费区可以取消吗」判低分（命中无意义词条），「希望有孩子可以参与的阅读活动」判高分；softr 基准用例复现 134 / -30 两个基准分。
- 自动测试共 71 项（包含父测试）全部通过：新增 `test/feedback-scoring.test.js`（引擎基准分、安全硬升级、用户示例、等待加成与优先级判定）与删除接口子测试（仅本人可删、已回复拒绝删除、跨用户/匿名拒绝、删除后列表不含该行）；原有 58 项零回归。
- 环境备注：Windows，Node.js 22.22.2；项目路径含中文导致 embedded-postgres 经 Node spawn 启动 initdb 时二进制路径字节被破坏（复现为 GBK 字节被替换），本轮通过 ASCII 路径目录联结（`C:\pg-ep-x64` → 二进制）修复后由 `npm test` 自行初始化临时实例完成全量验证。
